NWB File Creator

Turn cleaned spreadsheets into Neurodata Without Borders files, ready for DANDI. Everything runs inside your browser: your data never leaves your computer.

1Get the template

The template is a small, complete example dataset (two mice, one session each) plus a blank metadata workbook and a README that explains every column.

Download template (.zip) Blank metadata workbook Read the README

2Organize your data like this

my_dataset/
├── metadata.xlsx            sheets: Dataset, Subjects, Sessions, Devices
└── sub-<subject_id>/
    └── ses-<session_id>/
        ├── trials.csv       optional: start_time, stop_time, any other columns
        └── wheel.csv        time series: time_s, then columns like "speed [cm/s]"

Every row in the Sessions sheet needs a matching folder. In each time series CSV, the first column is time_s (seconds from session start) and each other header carries its unit in brackets.

4Look at the result

Open your file in Neurosift (drag it onto the page), or in Python:

from pynwb import NWBHDF5IO
with NWBHDF5IO("sub-AAX_1_ses-01.nwb") as io:
    nwb = io.read()
    print(nwb.subject, nwb.acquisition["wheel"], nwb.trials.to_dataframe())

This tool covers behavior-style data (time series and trials). For raw electrophysiology, imaging or video, use NWB GUIDE or NeuroConv.

Built with pynwb, NWB Inspector and Pyodide. The converter is a single Python file, convert.py, which also runs on your own computer: python convert.py my_dataset out_folder.
